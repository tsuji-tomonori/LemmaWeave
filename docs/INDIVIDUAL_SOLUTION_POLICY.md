# 一問ずつの記述式解答とLean化（2026-09-06）

ユーザーの最新指示を反映し、本書は従来の独立レビュー・全依存分類による停止条件に優先する。

1. LLM自身が一問ずつ問題文を読んで意味を確認し、日本語の解答を考える。参考解答も誤りうるため別に照合する。
2. 記述式解答の各行に、根拠、適用条件、結論、対応する名前付きLean定理を置く。中学までの分数・一次方程式・割合等は説明上の既習とする。それ以上の条件付き確率・乗法公式・排反分割・独立性などは説明を展開する。
3. 原題から何を事象・数量・定義域に対応させたかを先に明示する。答えを仮定しない。条件不足なら矛盾しない複数の具体例、可能範囲、追加条件による答えを説明する。
4. スクリプトは取得、保存、ビルド、対応検査に用いる。数学の解答はキーワード規則や全探索から自動生成しない。Leanの `norm_num` / `ring` / `linarith` は、明示した既習の算術・式変形の証明項を作るために用いる。
5. 意味の照合は作成エージェント本人でよい。`self_review_only` は停止理由ではない。照合者・内容・モデル版を残す。
6. `solution_ready` は、個別LLM解答、作成者照合、各行のLean宣言とその行からの根拠依存の対応、現在の成功実行、公理検査が揃った状態。自然言語と形式モデルの対応は人間／LLMの照合でありLeanだけの保証ではない。
7. 独立レビュー、全mathlib宣言の教育分類、分野網羅、教材の体系化は後続作業。旧AC01–12の総合監査の数値とは別軸にし、これらが未完でも次の問題を解く。

## 今回の表現

有限母集団を二つの属性A,Bで4つの排反部分へ分け、その相対度数を非負有理数で表す。合計1をモデルに含める。これは有限母集団の問題用であり、一般の連続確率空間の形式化を完了したという意味ではない。正の行の中での比を条件付き確率として定義し、乗法公式はその定義から証明する。

各レシピの `solution_format=individual_lines_v1` に対し、`lean_declaration` と説明行を対応させる。最終根にその行の宣言が到達し、その宣言の依存に `uses_nodes` と `requires_steps` の宣言があることを検査する。行の実際の型も報告書へ保存する。依存の存在は自然言語の意味の自動証明ではないため、別途 `author_review` に原題との照合を記録する。
