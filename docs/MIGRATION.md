# 既存試作の移行

前回の試作は、公開元51件・36大学・30学習モジュールの案と、共通テストの3小問・7解答欄、独自の二次関数教材を含む。HTMLにはLean検証済み0件、Lean草案未コンパイル、独立命題レビュー未実施と明記されている。今回の設計でも、その状態を引き継ぐ。

## 移行方針

- 掲載元51件は `source` の候補として再利用し、問題数にしない。古いリンク・規約・掲載年度を再確認する。
- 3小問は原資料との照合をやり直して問題台帳へ移す。7解答欄を7問題にはしない。
- 既存のLean草案は `work/legacy/` 等へ保管し、実ビルドと監査後に合格領域へ昇格する。
- Pythonの検算成功は補助証拠として保持し、Leanの実行証跡へ転用しない。
- 独自の二次関数例は `synthetic` とする。基盤テストや教材例に使っても、実入試の収集件数には混ぜない。
- 30学習モジュールは分類の候補であり、文部科学省の項目別照合済みbaselineとは扱わない。
- 旧ID・旧ファイル名・旧ハッシュ・新IDの対応表を作る。誤った状態があっても履歴を消さず訂正する。
- 既存ZIPに含まれるスクリプトは確認なしに実行せず、挙動を読んで必要なものだけ採用する。
