# 事象を重複しない二つに分ける

B=(A∩B)∪(¬A∩B)なのでP(B)=P(A∩B)+P(¬A∩B)。

条件：Aと¬Aは全体を尽くし、共通部分が空である。

使う場面：求める事象が起こる経路を場合分けして合計するとき。

## 根拠と分解

- Bに属するものはAに属するか属さないかのどちらか一方。
- 4セルのうちBの2セルの重みを合計する。重複も数え漏れもない。
