# 等確率の抽出を個数の比で表す

全要素を同じ確率で選ぶと、該当する要素の確率は該当数÷全体数。

条件：全要素を等確率で選ぶ。全体が空でない。

使う場面：確率と他の色の個数から未知の個数を逆算するとき。

## 根拠と分解

- 全体n個それぞれが選ばれる確率は1/n。
- 該当するx個は互いに異なるので、該当確率はx/n。今回はこの相対度数モデルを原題に対応させる。
