# 成功回数の期待値と期待値の線形性

有限標本上で、各回の成功指示変数I_iの期待値がpなら、n回の成功回数の期待値はE[ΣI_i]=ΣE[I_i]=np。

条件：有限標本・有限回数。確率としては重みが非負で総和1、指示変数は成功時1・失敗時0。各回の成功確率pが同じ。線形性自体には独立性は不要。

使う場面：復元抽出などで、何回成功するかの平均を求める。必ずその回数起きるとは主張しない。

## 根拠と分解

- 成功回数を0/1の指示変数の和として表す。
- 有限期待値をΣω w(ω)X(ω)と定義する。
- 分配法則と有限二重和の順序交換によりE[ΣI_i]=ΣE[I_i]。
- 指示変数の平均は成功確率pであり、pをn個足すとnpになる。
