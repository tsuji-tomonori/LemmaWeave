# 積の関係から部分量を求める

部分量×分母=全体 ⇔ 部分量=全体÷分母。

条件：すべて有理数で、分母≠0。

使う場面：半分、何分の一という条件から量を求める。

## 根拠と分解

- 両辺を0でない分母で割る。
- 逆向きには分母を掛け、元の保存式へ戻る。
