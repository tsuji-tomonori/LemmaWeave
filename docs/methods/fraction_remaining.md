# 残量の一定割合を取る

使用量+残量=全体、次の量=r×残量なら、次の量=r×(全体−使用量)。

条件：同一単位の有理数量。残りの一部なら0≤r≤1と0≤使用量≤全体を確認。

使う場面：残っているページの半分など、基準量が変わる割合。

## 根拠と分解

- 割合の基準が元の全体でなく残量であることを確定する。
- 保存式を使って残量を全体−使用量へ置き換える。
