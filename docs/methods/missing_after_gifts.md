# 自己資金と援助から不足額を分離する

自己資金+援助+r×援助+不足額=価格 ⇔ 不足額=価格−自己資金−(1+r)×援助。

条件：同一通貨の有理数量。不足額の非負性は別条件。

使う場面：二つの援助に倍率関係がある購入計画。

## 根拠と分解

- 援助+r×援助を(1+r)×援助にまとめる。
- 価格から自己資金と援助合計を引く。
