# 余事象の確率

P(B)=1-P(¬B)。

条件：Bと¬Bが全体を尽くし、重複せず、全確率が1。

使う場面：反対側の確率がわかっているとき。

## 根拠と分解

- 4つの部分の重みの合計は1。
- B側の2部分と¬B側の2部分に分け、移項する。
