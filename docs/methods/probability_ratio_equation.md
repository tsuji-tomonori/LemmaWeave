# 等確率の個数比を方程式にする

全体n個、該当x個を一様に選ぶと確率x/n。x/n=pかつn≠0ならx=pn。

条件：全要素を等確率で選ぶ。全体が空でない。

使う場面：確率と他の色の個数から未知の個数を逆算するとき。

## 根拠と分解

- 該当数を全体数で割った比を確率に対応させる。
- 分母が正だと確認し、両辺に全体数を掛ける。
