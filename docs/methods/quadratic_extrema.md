# 平方完成と端点・頂点から二次関数の極値を示す

f(x)=2x²−8x+5、0≤x≤3の最大値と最小値を、全域の上下界と達成に分けて示す。

**既存入試1小問の別証明。新規問題数には加えない。**


## S1：頂点形式へ変形

条件：xは実数。元の多項式と恒等的に等しい形へ変形する。

根拠：[平方完成](complete_square.md)

得られること：f(x)=2(x−2)²−3。

## S2：全域で下界を示す

条件：二次の係数2は非負。

根拠：[平方の非負性による下界](vertex_lower.md)

得られること：すべてのxでf(x)≥−3。

## S3：区間で上界を示す

条件：l=0,u=3,h=2なのでl+u=3≤4=2h、0≤x≤3。

根拠：[左端点による上界](left_endpoint_upper.md)

得られること：f(x)≤f(0)=5。

## S4：達成していることを確認

条件：0と2はいずれも区間[0,3]に含まれる。

根拠：[頂点で下界を達成](vertex_attainment.md)

得られること：x=2で−3、x=0で5。上下界と達成を合わせ、最小値−3・最大値5。
