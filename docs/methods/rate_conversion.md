# 単価と時間の単位を換算する

(単価÷単位時間)×時間 = 単価×(時間÷単位時間)。

条件：有理数の恒等式。実際の換算では単位時間>0、同一の一定単価、途中の丸めなし。

使う場面：時給と分単位の時間から報酬を求める。

## 根拠と分解

- 1時間=60分なので、時給を60で割ると分給となる。
- 分給に分数を掛ける方法と、時間へ換算する方法の一致を示す。
