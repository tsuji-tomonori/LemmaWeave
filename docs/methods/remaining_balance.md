# 保存式から残量を求める

使用量+残量=全体 ⇔ 残量=全体−使用量。

条件：同じ単位の有理数。物理的な残量には0≤使用量≤全体を別途確認。

使う場面：使用後の残り、読み終えていないページ数を求める。

## 根拠と分解

- 両辺から使用量を引く。
- 逆向きは使用量を足して全体との一致を確認する。
