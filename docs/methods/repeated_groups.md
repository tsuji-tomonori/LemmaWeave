# 同じ量の反復を期間まで積み上げる

(一回の量×対象数×期間内の回数)×期間数 = 一回の量×(対象数×(回数×期間数))。

条件：同じ活動を同じ頻度で繰り返すモデル。期間数や端数の扱いは原題から独立に確認する。

使う場面：一週間の作業量から指定週数の総量を求める。

## 根拠と分解

- 一回の量に対象数と週当たりの回数を掛ける。
- 指定週数を掛ける。一年の週数を暗黙に追加しない。
