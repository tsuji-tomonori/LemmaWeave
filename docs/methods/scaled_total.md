# 基準量とその一定倍を合計する

追加量=r×基準量、合計=基準量+追加量なら、合計=(1+r)×基準量。

条件：同じ単位の有理数量。個数として読むときは非負整数であることを別途確認。

使う場面：前月の半分、前日の2倍などの量を合計する。

## 根拠と分解

- 追加量の関係を合計式へ代入する。
- 分配法則で基準量をくくる。
