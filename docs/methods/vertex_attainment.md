# 頂点で下界を達成

a*(h−h)²+k=k。

条件：a,h,kは実数。最小値の主張に使う場合、下界証明とhが定義域に属する証明を別途要する。

使う場面：下界が実際に達成されることを示す。

## 根拠と分解

- hを代入すると平方項が0になる。
- 下界と定義域内の達成を組み合わせて最小値とする。
